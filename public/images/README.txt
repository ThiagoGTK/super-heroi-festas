Para trocar por outra foto/vídeo, basta substituir o arquivo mantendo o
mesmo nome, ou adicionar novos arquivos em galeria/ e incluir um novo
item no array FOTOS em src/components/Galeria.jsx (use type: "video"
para vídeos, sem esse campo para fotos).
